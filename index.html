왜 최종 배당만 쓰는지

이 화면을 진짜 데이터로 돌리려면

지금 보이는 숫자는 전부 연습용으로 만들어낸 가짜야. 틀은 실제와 똑같이 짜놨으니까, 아래 4가지만 채우면 진짜로 돌아가.

  1. 배당을 받아올 곳부터 정하기"The Odds API"라는 서비스에 가입하면 열쇠(키) 하나를 줘. 무료로 한 달에 500번까지 배당을 받아올 수 있고, 축구·야구·농구 대부분 나와. 사이트를 직접 뒤지는 것보다 훨씬 편해.
  2. 30분마다 배당을 받아서 저장하기여기가 제일 중요해. 덮어쓰지 말고 계속 쌓아야 해. "9월 21일 오후 3시, 맨시티 배당 1.80" 이런 줄을 하나씩 계속 추가하는 거야. 이렇게 쌓여야 "어? 아까보다 배당이 떨어졌네"를 알 수 있어. 저장은 엑셀 파일이나 작은 데이터베이스면 충분해.
  3. 경기 시작 직전 배당을 따로 저장하기아카이브의 핵심이야. 경기 시작 10분 전쯤 사이트 5곳의 배당을 한 번 더 받아서 '최종 배당'으로 따로 표시해둬. 경기가 끝나면 어느 팀이 이겼는지도 같은 줄에 적어. 이 두 가지가 있어야 "어느 사이트 배당이 맞았나"를 나중에 찾아볼 수 있어.
  4. 매주 자동으로 채워 넣기일주일에 한 번, 지난 주에 끝난 경기의 결과를 받아와서 빈칸을 채우는 작업을 예약해두면 돼. 일요일 밤에 한 번 돌게 걸어두면 손 댈 일이 없어. 그러면 아카이브가 계속 쌓여.
  5. 배당 숫자로 모아서 보기최종 배당과 결과가 한 줄에 다 있으면 "배당 1.77을 받은 팀은 과거에 몇 % 이겼나", "두산은 배당 1.60 미만일 때 몇 승 했나"를 바로 뽑을 수 있어. '지난 경기 기록' 탭이 그걸 하는 화면이야.
  6. 알림 받고 화면으로 보기움직임이 잡히면 카카오톡이나 텔레그램으로 보내고, 이 화면 같은 걸로 확인. 컴퓨터를 계속 켜둘 필요는 없고, 무료 서버 하나 빌려서 돌려도 돼.

알아야 할 계산 4개

1. 배당을 확률로 바꾸기

1을 배당으로 나누면 끝. 배당 2.50이면 1 ÷ 2.50 = 0.4, 즉 이길 확률 40%로 본다는 뜻이야.

확률 = 1 ÷ 배당
2. 사이트 수수료 알아내기

양쪽 확률을 더하면 100%가 나와야 정상인데, 실제로는 105%처럼 넘게 나와. 그 초과분이 사이트가 떼가는 수수료야. Pinnacle은 2% 정도로 싸고, 보통 사이트는 5~6%를 떼.

수수료 = (모든 확률을 더한 값) − 100%
3. 수수료 빼고 비교하기

사이트마다 수수료가 다르니까 그대로 비교하면 안 돼. 수수료를 걷어내서 합이 딱 100%가 되게 맞춘 다음에 비교해야 공평해.

비교용 확률 = 그 팀 확률 ÷ (모든 확률을 더한 값)
4. "돈이 쏠렸다"고 판단하는 기준

한 사이트만 움직인 건 그냥 실수일 수 있어. 여러 사이트가 동시에 같은 방향으로 움직여야 진짜 신호야. 그래서 조건 두 개를 같이 봐.

① 3시간 사이 확률이 2.5%p 넘게 올랐다
② 5곳 중 3곳 이상이 같은 방향으로 움직였다

배당 받아오는 프로그램 (파이썬)

30분마다 배당을 받아서 odds.db 파일에 쌓는 코드야. 열쇠(키)만 바꿔 넣으면 바로 돌아가.

import requests, sqlite3, time
from datetime import datetime

KEY = "발급받은_키"
SPORT = "soccer_epl"

db = sqlite3.connect("odds.db")
db.execute("""CREATE TABLE IF NOT EXISTS snap(
  ts TEXT, game_id TEXT, commence TEXT,
  home TEXT, away TEXT, book TEXT,
  outcome TEXT, price REAL)""")

def collect():
    r = requests.get(
        f"https://api.the-odds-api.com/v4/sports/{SPORT}/odds",
        params={"apiKey": KEY, "regions": "eu",
                "markets": "h2h", "oddsFormat": "decimal"})
    ts = datetime.utcnow().isoformat()
    for g in r.json():
        for bk in g["bookmakers"]:
            for o in bk["markets"][0]["outcomes"]:
                db.execute("INSERT INTO snap VALUES(?,?,?,?,?,?,?,?)",
                    (ts, g["id"], g["commence_time"],
                     g["home_team"], g["away_team"],
                     bk["key"], o["name"], o["price"]))
    db.commit()

while True:          # 30분마다
    collect()
    time.sleep(1800)

꼭 알아둘 것

경기 직전 배당이 제일 정확해. "지난 경기 기록" 탭에서 확인할 수 있는데, 처음 나온 배당보다 경기 직전 배당이 결과를 더 잘 맞혔어. 배당은 전 세계 돈이 몰리면서 계속 다듬어지거든.

그래서 목표를 "내가 배당보다 잘 안다"가 아니라 "느린 사이트가 아직 못 따라왔다"를 찾는 쪽으로 잡는 게 현실적이야. 이게 이 프로그램이 하는 일이야.

그리고 지금 화면의 적중률·수익률 숫자는 가짜 데이터라 아무 의미가 없어. 진짜 데이터를 최소 6개월은 그냥 쌓아놓고 검증한 다음에 판단해야 해. 국내에서 스포츠 베팅은 합법 범위가 제한돼 있으니, 이건 배당 데이터를 들여다보는 분석 도구로 보는 게 맞아.
